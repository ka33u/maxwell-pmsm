# 通过 MCP 操作 Maxwell 2023 R2

Ansys 的 PyAEDT-MCP 是独立的本机进程。客户端用 stdio 调用 MCP 服务，服务通过 PyAEDT 和本机 gRPC 连接 AEDT。环境需同时具备可运行的 Python 服务、相应版本的 AEDT 和所需许可证。可用工具以该服务实际返回的 `tools/list` 为准。[官方安装说明](https://aedt-mcp.docs.pyansys.com/version/stable/getting_started/installation.html) · [0.2.4 源码](https://github.com/ansys/pyaedt-mcp/tree/v0.2.4)

## 建立和确认会话

1. 在受信任的项目中加载 MCP 配置，查询工具列表、本机安装和当前会话。此工作站使用 D 盘项目独立环境，`ANSYSEM_ROOT232` 指向 `E:\AnsysEM\v232\Win64`。显式选择 `2023.2`。进程级 `TMP` 和 `TEMP` 可指向 D 盘，AEDT 的软件级临时目录另查启动日志。
2. 如任务涉及正在使用的桌面，先核对 PID、版本和工程。无人值守验证可新建无界面实例，记录其 PID 或 gRPC 端口。结束时只关闭本次启动的实例。已有用户会话仅断开客户端连接。
3. 使用唯一目录中的副本，已求解工程同时复制同名 `.aedtresults`。保持工程名及结果目录名配对，保留原件哈希。用本机可写的短英文路径排查旧版工程转换或保存失败。
4. 打开副本后，从活动 Desktop 和 Design 回读版本、工程**完整路径**、设计名、解类型和 setup。Windows 联接产生两个不同路径字符串时可用 `os.path.samefile` 核对。检查工具返回正文、AEDT 消息和实际文件。工具发现、打开成功和求解完成分别记录。

此项目的 Codex 服务名为 `maxwell_aedt`，在项目根目录执行 `codex mcp get maxwell_aedt` 可检查配置。本机验证组合为 Python 3.12、`ansys-aedt-mcp==0.2.4`、`pyaedt==1.10.0`、`mcp==2.3.0`、`fastmcp==4.2.4`。服务入口是 `mcp_runtime/venv/Scripts/ansys-aedt-mcp.exe`，项目配置向该进程传入 `PYAEDT_USE_PRE_GRPC_ARGS=True` 以使用旧版启动参数。此次默认配置在连接前后均列出 20 个工具，工程操作需先建立桌面连接。[官方工具实现](https://github.com/ansys/pyaedt-mcp/blob/v0.2.4/src/ansys/aedt/mcp/tools.py) · [旧版 gRPC 参数](https://aedt.docs.pyansys.com/version/stable/Getting_started/ClientServer.html)

| 操作 | 0.2.4 工具与核查要点 |
|---|---|
| 查版本及会话 | `check_aedt_installed`、`check_aedt_status`；核对 2023.2 的安装路径。 |
| 新建或附着 | `launch_aedt` 显式指定版本；`connect_to_aedt` 连接已确认的本机端口。连接后再次列工具。 |
| 选工程和设计 | `open_project`、`list_designs` 后通过 `run_python_code` 读取 `odesktop.GetActiveProject()` 和活动设计。 |
| 调用已有建模或求解脚本 | `run_python_script` 交给 AEDT 的脚本解释器。项目原生 runner 的哈希、输入配置和日志仍然有效。 |
| 操作已配置的 setup | `analyze_design` 指定工程、设计和 setup。异步模式由调用方检查结果是否已落盘。 |
| 导出 Maxwell 瞬态曲线 | `run_python_code` 通过 `ReportSetup` 导出 CSV。每次调用重新取得工程和设计，用 `result` 返回明确的核查值。 |
| 释放本次实例 | `disconnect_from_aedt` 显式选择是否关闭工程和桌面，并回查所属进程。 |

## 执行与验收

给旧版频谱或定相脚本提供输入时，运行 `python scripts/normalize_noload_emf.py --csv "<原始导出>" --out "<新文件.csv>"`，得到统一为 ms、V 的派生文件。保留原始报表和哈希。独立新求解已通过 `run_python_script` 在 75 kW 空载算例完成；本次未验证 `analyze_design` 直接求解、带载或损耗。

- **回读已有解**。在已求解的 setup 上新建唯一命名的临时报表，经 D 盘短英文路径导出到新文件，确认文件存在后再移除临时报表、归档原始 CSV。此次长中文目标路径的调用正常返回但没有文件，短英文路径导出成功。2023 R2 重新打开工程后可能自动选用 mV。按各相列名和单位换算为 V，再求相差、基波或 RMS。历史频谱脚本中有按数值直接当 V 使用的接口，传入前核对其单位要求。
- **比较同一解的两次导出**。对本项目标准空载算例运行 `python scripts/compare_noload_exports.py --case "<已审计空载算例>" --export "<新导出.csv>" --out "<新比较.json>"`。脚本重审基准日志、设置和时间窗，比较各相每一个共同时间点，输出最大绝对差和两个文件的哈希。默认容差为 0.000001 V，只用于同解导出一致性。版本复算、网格收敛和实测误差各自选取相应指标与容差。
- **新求解**。确认目标 setup、运动转速、激励、材料和停止时间；提交一次并记录工程、setup、时间及 PID。连接超时先查看求解进程、锁和 profile，待状态明确再决定是否重试。确认 solver 正常结束、工程保存、结果目录、完整时窗和原始波形后再报告。现成原生批脚本及独立审计仍可用于该流程。[原生工具](local-toolchain.md) · [证据审计](verification.md)
- **能力记录**。分别记录发现服务、连接指定版本、打开工程、导出同一解、新求解及具体工况。跨版本空载复算见项目 `upgrade_validation_2023R2_20261121`；MCP 验证记录见 `skill_validation_2023R2_mcp`。每次更换服务、PyAEDT 或 AEDT 版本时，在该组合上重复一个有基准的算例。

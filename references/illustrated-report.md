# 单页仿真报告与净材料计价

将两规格的局部槽型、电磁性能、气隙与铁芯磁密、材料用量和成本排在一张 A3 横页。PDF 用于打印，PNG 用于直接看图。随页交付便携数据包，保留单位、工况、时间窗、原波形和成本明细。

## 数据准备

1. 从审计通过的空载、指定电流角带载和独立损耗算例读取实际 CSV。按表头归一电压、电流、时间和损耗单位。分别标明反电势线间或相值、基波或全波，转矩均值和峰峰值，电磁功率，定转子铁耗、模型 SolidLoss、按相电阻估算的直流铜耗。额定效率、功率因数等设计单数据须标明来源。比较历史求解时，将每组数值与相应 AEDT 版本和时间窗对应。
2. 依照[磁密工作流](flux-density.md)汇总空载和带载的气隙 Br、齿身和轭部矢量模，同时列出瞬时峰值、RMS、均值及单点周期 RMS 的最大值。在数据包内保留各帧和各点的数据、坐标和实际采样时刻。
3. 从标注与模型的槽口、斜肩、切点、底圆弧重建完整**单槽**局部视图，保持横纵等比例。标出口宽、口深、肩宽、肩角、hs12、槽底半径和总深。核对槽底直径、定子内外径、轭厚、叠长和最小气隙。若有磁槽，列出磁槽、磁钢、铁桥和轴向分段尺寸。对不同槽型，替换轮廓与尺寸基准。
4. 优先采用设计单净重和实际采购价。没有采购价时，可用带日期、牌号、币种及单位的公开参考价。净材金额为净重 × 参考单价，给出分项及单台合计。漆包线替代铜材价格、毛坯代替成品、成材率、税运、加工和其他部件的边界需随数值标注。来源计价单位若为元/吨须先除以 1,000。缺失单价可保留待报价项，注明已报价小计的范围。

## 复用出图

当前两个内转子、圆底半闭口槽的可复算样例位于 D 盘项目的 `两规格仿真报告_20261123`。在项目根目录运行下列命令。第一条用源数据、可替换的 `材料计价.json` 更新报告与数据包。第二条使用已整理好的快照，仅重绘 PDF 和 PNG，也可用于解压后的便携数据包。

```text
mcp_runtime\venv\Scripts\python.exe -B -X utf8 两规格仿真报告_20261123\build_report.py
python <skill>/scripts/render_motor_sheet.py <报告数据.json> <输出文件基本名> --font <中文字体文件>
```

渲染器使用 NumPy、Matplotlib，字体默认 Microsoft YaHei。以样例 `报告数据.json` 为字段模板。两个 `motors` 各有 `geometry.inputs` 与 `geometry.slot_geometry`、标注文字、实际带载气隙波形（机械角、Br）。页面的表头及数据行由 `flux_*`、`performance_*`、`cost_*` 提供。单页可排 10 行磁密、14 行性能和 4 行成本，每行列数与表头一致，成本末行为合计。超过该容量时，选择有代表性的显示指标并在附件保留全量，或调整版式。

交付前渲染 PDF，检查仅一页、中文和单位符号齐全、槽型标注清晰、波形坐标可读。抽核峰值与 RMS、相电流与时间窗、成本乘法及合计。用清单核对数据包的完整性并在独立目录试读，确保解压后不依赖求解机盘符即可查看数据。

## 单规格报告

单机版本并排绘制定子单槽、一极装配截面、带 B/H/L 尺寸的单块磁钢，以及磁槽端部放大图。用图纸标注确定磁钢宽厚和轴向长度，按模型坐标显示磁钢位置、极弧、中桥、气隙。若图纸的端部圆角及扩腔在求解中已简化，先将转换图元按轴心和极轴配准，再叠加标识图纸、求解轮廓和磁钢。横向扩腔增量、模型留隙及成品装配公差有各自的量测基准。

单机快照含六组原始波形，分别为三相空载反电势、带载电流、转矩、磁链、空载与带载末帧气隙 Br、带载齿轭固定点磁密。时域表按原始时间和单位归一，磁密固定点须跨帧保持同一坐标。当前样例选取各区域周期有效值最高的固定点，并用原始矢量重算该点周期有效值与汇总结果对照。随每份 PDF / PNG 提供独立数据包，写明有限元求解版本、二维几何简化、模型与成本所用材料及价格依据。

在项目根目录运行 `mcp_runtime\venv\Scripts\python.exe -B -X utf8 单规格仿真报告_20261123\build_single.py` 可从原始数据生成两份报告。解压任一型号的数据包后，使用 `python <skill>/scripts/render_single_motor.py <报告数据.json> <输出文件基本名>` 可仅凭该型号快照重绘。该版式适用于内转子、圆底半闭口定子槽和每极横排两块矩形磁钢。其他拓扑按实际截面替换轮廓和标注。

# Offline dq consistency check

Use `scripts/offline_dq.py` only after independently checking both saved no-load and load cases with `audit_case.py`. It implements the amplitude-invariant 2/3 Park transform, informed by the official Ansys PMSM example: https://github.com/ansys/pyaedt-examples/blob/main/examples/low_frequency/motor/aedt_motor/pm_synchronous.py .

```powershell
& $motorPython '<skill>\scripts\offline_dq.py' --noload '<completed-no-load-case>' --load '<completed-load-case>' --out '<new-output.json>'
```

The case layout, file names and exact CSV column order/units must match the local full-model generator, with `Time [ms]`. The load configuration must still reference the same absolute source no-load project and unchanged source project/configuration hashes; moved files fail this check. The tool checks each case's configured frequency, cycles and step against its complete uniform time grid from zero to stop. No-load and load may have different cycle counts, but their time steps must match. It requires positive synchronous speed and ABC phase sequence; ACB, reversed rotation and arbitrary project layouts are not supported. See the tool's `--help`, JSON and errors. Do not bypass a lineage mismatch by editing hashes.

The d axis is inferred from the no-load A-phase EMF fundamental assuming `e=dλ/dt`; it is not measured or verified against the geometric magnetic axis. Inspect reported voltage/flux-difference residuals, initial angle, sequence, waveform and stability before interpreting the output. dq currents are peak quantities. Compare dq cross-product and Maxwell torque in a common window as an internal consistency check from the **same** solution; sampled torque ripple can differ because the dq approximation does not automatically account for all spatial harmonics. Both the dq power inner product and flux-current cross product are invariant to a common rotation of the d/q axes. Their agreement cannot validate axis offset, the actual magnetic axis or the physical interpretation of id/iq and flux components. This check does not establish actual motor performance or convergence.

For the last no-load EMF and load-current cycles, output reports each phase's fundamental RMS, positive/negative/zero-sequence RMS and negative/positive and zero/positive magnitude ratios. The ABC convention is `B=A·exp(-j120°)` and `C=A·exp(+j120°)` for positive sequence. Ratios are dimensionless and are `null` when positive sequence is too small for a meaningful ratio. These values describe only the configured-frequency fundamental; they do not measure total harmonic distortion or certify the wiring. The ±5° check on relative fundamental phase angles is a format precondition, not proof of phase balance or the actual supply. No balance acceptance threshold is imposed; compare with the task's criteria if available.

One load point cannot identify independent Ld/Lq or incremental inductances under saturation and cross-coupling. Obtain and verify an appropriate Maxwell inductance matrix or independent d/q current perturbation cases before reporting those quantities. On the two local exploratory examples this method was tested against stored data; that is not validation for other motors or actual winding connections. Script and tests use Python standard library and were checked on AEDT CPython 3.7; the workspace-specific real-data test skips if its inputs are unavailable.
